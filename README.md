📊 Zomato Restaurants Dashboard
📌 Overview
This project provides an interactive Excel dashboard built using restaurant data from Zomato. The dashboard helps analyze restaurant performance, customer preferences, and key business metrics in a visually engaging way.

🎯 Objectives
Explore restaurant distribution across cities and cuisines

Track ratings, reviews, and customer engagement

Compare cost trends for two people across different locations

Identify top restaurants by popularity and performance

🛠️ Features
Dynamic Filters: Slice data by city, cuisine, or price range

KPIs: Cards for average rating, total restaurants, cost for two, and votes

Charts & Visuals:

Bar charts for cuisine popularity

Pie charts for restaurant distribution

Trend lines for cost vs. rating

Interactive Dashboard: Clickable visuals for drill‑down analysis

📂 File Contents
zomato restaurants.xlsx → Main dataset and dashboard

Sheets included:

Raw Data → Original dataset

Cleaned Data → Processed and structured data

Dashboard → Interactive visuals and KPIs

🚀 How to Use
Open the Excel file in Microsoft Excel (2016 or later).

Navigate to the Dashboard sheet.

Use slicers and filters to explore data interactively.

Review KPIs and charts for insights into restaurant trends.

📈 Insights You Can Gain
Which cuisines are most popular in different cities

Cost distribution for two people across restaurants

Relationship between ratings and votes

Top‑performing restaurants by customer engagement

🔧 Requirements
Microsoft Excel 2016 or later

Power Query (for data cleaning)

Pivot Tables & Pivot Charts

📝 Notes
Data is based on Zomato’s restaurant listings.

Dashboard is designed for exploratory analysis and business insights.
